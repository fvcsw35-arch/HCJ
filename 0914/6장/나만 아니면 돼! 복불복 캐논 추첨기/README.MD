# 구슬 장애물 추첨기 (Marble Lottery)

참가자 명단을 입력하고 장애물이 있는 핀볼/구슬 낙하 캔버스 시뮬레이션을 통해 최종 당첨자(최후의 생존자)를 선출하는 웹 기반 추첨 애플리케이션입니다.

---

## 주요 기능

* **참가자 명단 입력 기능**:
  * 쉼표(`,`) 또는 줄바꿈(`\n`)을 구분자로 활용하여 다수의 참가자 이름을 손쉽게 입력
* **핀볼/구슬 장애물 시뮬레이션**:
  * HTML5 Canvas($500 \times 700$ 해상도)를 이용한 구슬 낙하 및 장애물 물리 연출
  * **"구슬 발사 및 추첨 시작"** 버튼을 통한 추첨 애니메이션 실행
* **당첨자 발표 오버레이**:
  * 추첨 완료 시 트로피 아이콘과 함께 "최후의 생존자 (당첨자)" 결과 창 표시[cite: 7]
  * **"다시 추첨하기"** 버튼으로 손쉬운 재추첨 기능 제공[cite: 7]

---
