# PDF Merger - PDF 문서 병합기

여러 개의 PDF 파일을 업로드하고 드래그 앤 드롭으로 순서를 자유롭게 정렬한 뒤, 하나의 단일 PDF 파일로 손쉽게 병합할 수 있는 웹 기반 문서 처리 도구입니다.

---

## 주요 기능

* **다중 PDF 파일 업로드**:
  * 드래그 앤 드롭 또는 파일 선택 창을 통해 여러 개의 `.pdf` 파일 동시 선택 지원
* **드래그 앤 드롭 순서 변경**:
  * 파일 목록 내에서 마우스 드래그로 원하는 병합 순서 손쉽게 재배치
  * 실시간 병합 대상 파일 개수 수치 배지 표시
* **목록 관리 및 병합**:
  * 필요 없는 파일 개별/전체 삭제 기능[cite: 10]
  * 원클릭으로 순서가 맞춰진 단일 PDF 파일 생성 및 병합 처리[cite: 10]
* **실시간 로딩 피드백**:
  * PDF 데이터 처리 및 병합 과정 중 실시간 스피너 및 진행 상태 메시지 출력[cite: 10]

## 기술 스택 및 외부 라이브러리

* **Frontend**: HTML5, CSS3, JavaScript[cite: 10]
* **External Libraries**:
  * **pdf-lib (`v1.17.1`)**: 클라이언트 사이드에서 PDF 바이너리 데이터를 결합하고 새 문서로 병합[cite: 10]
