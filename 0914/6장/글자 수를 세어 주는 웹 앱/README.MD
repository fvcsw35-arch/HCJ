# 글자 수 & 바이트 계산기 (Text & Byte Counter)

텍스트를 입력하거나 붙여넣으면 실시간으로 글자 수와 바이트(Byte) 수치를 정확하게 계산해 주는 웹 기반 카운터 도구입니다.

---

## 주요 기능

* **실시간 수치 계산 (스코어 박스)**:
  * **바이트 계산**: 한글 2Byte 기준으로 실시간 바이트(Bytes) 수치 측정
  * **공백 포함 글자 수**: 띄어쓰기 및 줄바꿈을 포함한 총 글자 수 산출
  * **공백 제외 글자 수**: 공백을 제외한 순수 글자 수 산출
* **편의 기능**:
  * **초기화 버튼**: 클릭 시 입력된 텍스트 및 계산된 현황판 수치 리셋[cite: 5]
  * **복사하기 버튼**: 입력한 텍스트를 클립보드에 바로 복사[cite: 5]
