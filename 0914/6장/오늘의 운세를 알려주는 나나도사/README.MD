# 속성 오라클 - 오늘의 운세 (Fortune Oracle)

사용자의 개인 정보(이름, 생년월일, 성별)와 선택한 속성 기운을 바탕으로 오늘의 운세, 운세 지수, 상세 가이드 및 행운의 아이템을 분석해 주는 웹 애플리케이션입니다.

---

## 주요 기능

* **사용자 정보 입력 폼**:
  * **이름**: 사용자 이름 입력 지원
  * **생년월일**: 날짜 선택기(`input type="date"`)를 통한 생년월일 설정
  * **성별**: 남성/여성 라디오 버튼 선택 지원
* **오늘의 속성 선택**:
  * 5가지 속성 기운 버튼 지원 (`불`🔥, `물`💧, `나무`🌲, `땅`⛰️, `바람`🌬️)
* **운세 결과 상세 출력**:
  * **속성 기운 배지 및 사용자 맞춤 타이틀**: 선택한 속성 기운 및 사용자 이름 연동[cite: 11]
  * **운세 지수**: 점수 형태(예: 95점)로 측정된 운세 수치 제공[cite: 11]
  * **요약 및 상세 운세**: 오늘의 기운 흐름 요약 문구 및 행동 가이드 상세 설명 제공[cite: 11]
  * **행운의 아이템 정보**: 행운의 색상 및 행운의 숫자 안내[cite: 11]
* **다시 검사하기**:
  * 결과 화면에서 클릭 시 입력 폼으로 돌아가는 재검사 버튼 제공[cite: 11]
