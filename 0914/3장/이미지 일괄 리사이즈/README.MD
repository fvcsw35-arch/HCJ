# Smart Web Tools Collection

웹 브라우저에서 별도의 서버 업로드 없이 안전하고 빠르게 문서 압축 및 이미지 리사이징 작업을 수행할 수 있는 클라이언트 사이드 웹 애플리케이션 모음입니다.

---

## 1. Smart Doc Compressor (문서 압축기)

Word, PPT, PDF 및 이미지 파일의 용량을 압축하고 통합 관리하는 웹 도구입니다.

### 주요 기능 및 특징
* **다양한 파일 확장자 지원**: Word, PPT, PDF 및 다양한 이미지 포맷을 지원합니다[cite: 1].
* **드래그 앤 드롭 업로드**: 사용자 편의성을 높인 파일 끌어다 놓기 인터페이스를 제공합니다[cite: 1].
* **스캔본 PDF 압축**: PDF 페이지를 캡처하여 저화질 이미지를 재구성하는 방식으로 용량을 압축합니다[cite: 1].
* **실시간 처리 목록 제공**: 파일 업로드 현황 및 진행 상황을 한눈에 확인할 수 있습니다[cite: 1].

### 지원 파일 형식
* **WORD**: `.doc`, `.docx`[cite: 1]
* **PPT**: `.ppt`, `.pptx`[cite: 1]
* **PDF**: `.pdf`[cite: 1]
* **IMAGE**: `.jpg`, `.jpeg`, `.png`, `.webp`[cite: 1]
* **기타**: `.hwp` (파일 선택 및 업로드 감지 지원)[cite: 1]

### 핵심 기술 스택 및 외부 라이브러리
* **JSZip (`v3.10.1`)**: 오피스 문서 및 압축 구조 처리[cite: 1]
* **PDF.js (`v2.14.305`)**: PDF 문서의 각 페이지를 Canvas 형태로 렌더링 및 캡처[cite: 1]
* **jsPDF (`v2.5.1`)**: 캡처된 캔버스 이미지를 조합하여 새로운 압축 PDF 재생성[cite: 1]

## 2. Smart Image Resizer (이미지 편집/리사이저)

이미지 비율 조절, 자르기, 여백 추가 및 일괄 압축 다운로드를 제공하는 이미지 편집 도구입니다.

### 주요 기능 및 특징
* **다양한 캔버스 비율 선택**:
  * 프리셋 비율: `1:1`, `3:4`, `4:3`, `9:16`, `16:9`[cite: 2]
  * 커스텀 비율: 사용자가 직접 가로/세로 비율 입력 가능[cite: 2]
* **리사이즈 방식 설정**:
  * **Crop (자르기)**: 선택한 비율에 맞춰 이미지 영역을 자름[cite: 2]
  * **Padding (여백 추가)**: 원본 비율을 유지하고 지정한 색상의 여백을 채움[cite: 2]
* **여백 색상 커스텀**: Color Picker를 통해 Padding 여백 색상 자유 지정[cite: 2]
* **ZIP 일괄 다운로드**: 변환 완료된 여러 이미지 파일을 압축하여 한 번에 다운로드[cite: 2]

### 지원 파일 형식
* **IMAGE**: `.jpg`, `.jpeg`, `.png`, `.webp` 등 모든 이미지 파일 (`image/*`)[cite: 2]

### 핵심 기술 스택 및 외부 라이브러리
* **JSZip (`v3.10.1`)**: 편집된 변환 이미지를 ZIP 파일로 묶어 일괄 다운로드[cite: 2]
