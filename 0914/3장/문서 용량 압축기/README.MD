# Smart Doc Compressor

문서 및 이미지 파일의 용량을 압축하고 관리할 수 있는 웹 기반 문서 압축 도구입니다.

---

## 주요 기능

* **다양한 파일 포맷 지원**: Word, PPT, PDF, 이미지 파일 등 주요 문서 형식 지원
* **드래그 앤 드롭 지원**: 파일 선택 버튼뿐만 아니라 직관적인 드래그 앤 드롭 인터페이스 제공
* **다중 파일 처리**: 여러 개를 동시 선택하여 처리할 수 있는 목록 제공
* **클라이언트 사이드 처리**: 외부 외부 라이브러리를 활용해 브라우저 단에서 파일 및 PDF/오피스 압축 작업 수행

---

## 지원 파일 형식

* **WORD**: `.doc`, `.docx`
* **PPT**: `.ppt`, `.pptx`
* **PDF**: `.pdf` *(PDF.js 기반 페이지 캡처 및 jsPDF 재생성을 통한 스캔본 용량 압축)*
* **IMAGE**: `.jpg`, `.jpeg`, `.png`, `.webp`
* **기타**: `.hwp` *(파일 업로드 감지 가능)*

---

## 사용된 기술 스택 및 외부 라이브러리

* **HTML5 / CSS3 / JavaScript**
* **JSZip (`v3.10.1`)**: 오피스 문서(Docx, Pptx 등) 내부 구조 해석 및 압축 처리
* **PDF.js (`v2.14.305`)**: PDF 파일의 각 페이지를 Canvas 형태로 캡처 및 렌더링
* **jsPDF (`v2.5.1`)**: 캡처된 이미지를 조합하여 새로운 압축 PDF 문서 생성
