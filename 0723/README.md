# 🌊 강민석 - 개인 자기소개 & 포트폴리오 웹사이트

> **IT/AI 웹 개발자를 꿈꾸는 강민석의 개인 포트폴리오 웹 페이지입니다.**  
> 글래스모피즘(Glassmorphism) 스타일 디자인과 Deep Ocean 테마를 적용하여 개발자로서의 비전과 프로젝트, 기술 스택을 소개합니다.

---

## 📌 프로젝트 소개
이 프로젝트는 웹 표준 기술인 **HTML5**와 **CSS3**만을 활용하여 제작된 반응형 자기소개 페이지입니다.  
글로벌(일본) IT/AI 무대를 향해 도전하는 개발자로서의 비전, 기술 스택, 주요 프로젝트, 데스크 세팅 및 유용한 링크를 한눈에 볼 수 있도록 구성되어 있습니다.

---

## ✨ 주요 특징 및 기능

1. **반응형 & 글래스모피즘 UI 디자인**
   - CSS `backdrop-filter: blur()`와 투명도 조절을 활용하여 시각적으로 시원하고 모던한 UI 구현
   - PC 및 모바일(최대 650px 이하) 환경을 모두 고려한 미디어 쿼리 적용

2. **구조화된 섹션 구성**
   - **About Me:** 인적사항, 관심 분야, 개발 강점 소개
   - **Tech Stack & Languages:** 보유 기술 스택 그리드 배치
   - **Projects & Plan:** 현재 개발 중인 글로벌 커스텀 상품 거래 플랫폼 및 포트폴리오 소개
   - **Global Vision & Japan Plan:** 일본 진출 및 현지 활동 목표 명시
   - **Workspace & Coding Videos:** 작업 환경 이미지 및 유튜브 학습 영상 임베드 (16:9 비율 유지)
   - **Favorite & Fun Links:** 자주 방문하는 AI Tool, 개발 블로그, 게임/커뮤니티 링크 모음

3. **인터랙티브 요소를 활용한 배너**
   - 대화면(1240px 이상) 접속 시 좌/우 측면에 고정된 사이드 광고/연락처 날개 배너 배치
   - Hover 효과를 통한 사용자 경험(UX) 극대화
