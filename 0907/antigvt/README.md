# VISIT BUSAN - 日本人向け釜山3泊4日観光ガイド

日本人旅行者のための釜山3泊4日モデルコースおよび実用旅行案内を提供するレスポンシブWebサイトです。
20年目のWebパブリッシャーのノウハウを反映し、W3C標準規格、Webアクセシビリティ、セマンティックマークアップ、パフォーマンスを徹底して設計・実装されています。

## プロジェクト概要

- 対象ユーザー: 釜山を訪れる日本人自由旅行者(FIT)
- 主な提供情報: 
  - 日程別最適化ルート (Day 1〜Day 4)
  - 交通カード・決済情報 (WOWPASS, T-money, ビジット釜山パス)
  - 韓国内必須アプリ (NAVERマップ, カカオT, Papago)
  - ご当地グルメ・名物料理
  - 日本語緊急連絡先 (韓国観光公社1330, 日本総領事館)

## 技術仕様とパブリッシング特徴

1. HTML5 (セマンティックマークアップ):
   - header, nav, main, section, article, footer など意味に基づいたタグ選定
   - 見出しタグ(h1〜h4)の厳格な階層構造
   - WAI-ARIA属性(role="tablist", aria-selected, aria-controls, aria-expanded)によるアクセシビリティ担保

2. CSS3 (モダンデザインシステム):
   - CSSカスタムプロパティ(変数)による一元的なカラー・余白・シャドウ管理
   - モバイルファースト設計およびFlexbox/Gridによる高精度なレスポンシブ対応
   - 絵文字を使用せず、軽量で拡大縮小に強いインラインSVGアイコンを採用

3. JavaScript (バニラJS):
   - 外部ライブラリ非依存の軽量スクリプト
   - タブ切り替えによる日別タイムライン表示
   - モバイルハンバーガーメニューの開閉制御
   - スクロール検知によるヘッダーシャドウ制御およびスムーズトップ移動機能
