# 📄 강민석의 웹 이력서 (Web Resume)

> **IT/AI 웹 개발자를 목표로 하는 강민석의 HTML 기반 이력서 및 포트폴리오 페이지입니다.**  
> 개인 정보, 자기소개, 연락처, 보유 기술 스택 및 비디오/유튜브 미디어가 포함된 주요 프로젝트를 한눈에 확인할 수 있습니다.

---

## 📌 프로젝트 소개

본 프로젝트는 시맨틱 태그(Semantic HTML)를 활용하여 정돈된 구조로 작성된 온라인 이력서 웹 페이지입니다.  
원하는 상품 거래 사이트 운영을 목표로 IT/AI 분야 진출을 준비하는 과정과 주요 기술 스택, 수행한 프로젝트 결과를 시각적 미디어(비디오 및 유튜브 영상)와 함께 전달합니다.

---

## 🛠️ 기술 스택 (Tech Stack)

### Markup & Architecture
- **HTML5**: 시맨틱 태그 (`<section>`, `<ol>`, `<ul>`, `<video>`, `<iframe>` 등)를 활용한 정보의 구조화
- **CSS**: 외부 스타일시트 (`css/style.css`) 연동

### Skill Set (보유 기술)
페이지에 명시된 보유 기술 목록입니다:
- **Frontend**: HTML, CSS, SASS, JavaScript[cite: 2]
- **Backend & Script**: PHP, Ruby[cite: 2]
- **Mobile Platform**: iOS[cite: 2]

## 📂 프로젝트 상세 구조 (Content Sections)

웹 페이지는 총 5개의 핵심 섹션으로 구분되어 있습니다[cite: 2].

| 섹션 ID | 섹션명 | 주요 포함 내용 |
| :--- | :--- | :--- |
| `my_info` | **My info** | 프로필 사진 (`images/profile.jpg`), 이름(강민석), 직업(학생), 나이(38), 거주지(김해) 표 작성[cite: 2] |
| `about` | **About** | IT/AI 분야 취업 동기 및 상품 거래 사이트 운영 목표 작성[cite: 2] |
| `contact` | **Contact** | 전화번호, 이메일, 페이스북, 네이버 블로그 등 연락처 링크 목록[cite: 2] |
| `skill` | **Skills** | 습득한 프론트엔드, 백엔드, 모바일 개발 언어 및 기술 순서 있는 리스트[cite: 2] |
| `project` | **Projects** | 비디오/유튜브 영상이 첨부된 프로젝트 상세 내역[cite: 2] |
